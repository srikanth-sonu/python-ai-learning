# Lesson 01 - Python Execution

## Objective

Understand how Python programs are executed.

## Concepts Learned

- What is Python?
- What is a Python file (`.py`)?
- What is the Python Interpreter?
- What is the Terminal?
- How Python executes code

## Key Takeaways

- A `.py` file is just a text file.
- The Python interpreter reads and executes Python code.
- The terminal is used to run commands.
- Python code cannot execute by itself.

## Reflection

Today I learned that a Python file is only a text file. The Python interpreter is responsible for reading and executing the code. The terminal is used to run the interpreter and display the output.

## New Concepts Learned

### print()

- A function can accept multiple arguments.
- `print()` automatically separates multiple arguments with a space.
- The default separator is a single space.
- The `end` parameter controls what is printed after the output.
